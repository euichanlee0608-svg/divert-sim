회피하는 드론을,
측추력기로 요격하기.

비례항법으로 유도되는 소형 요격 미사일이 랜덤하게 회피하는 드론을 쫓는 2D 물리 엔진. 측추력기의 위치·힘·유도게인을 4가지 최적화 알고리즘으로 설계하고, 궤적을 프레임 단위로 재생한다.

비례항법 유도 RK4 물리 적분 4종 최적화 비교 실제 Coyote Block 2급 앵커링 지연·잡음 현실 모델
미사일 드론 측추력·기폭

최적화 4종 비교

동일한 목적함수(요격시간·연료·정확도의 가중합)를 최소화한다. 운용점: 드론 7g 회피 / 탐지거리 250m, 지연 반영. 낮을수록 좋음(J).

핵심 결과 — 요격에 필요한 최소 측추력 권한

위협(드론 회피 g × 탐지거리)이 거세질수록 명중에 필요한 측추력이 커진다. 'X'는 Coyote급 권한(≤300N)으로 90% 격추가 물리적으로 불가능한 영역 — 현실적 지연을 넣자 나타났다.

필요 최소 측추력 F_max [N] · 격추율 ≥ 90%
← 탐지거리 R_det [m] →

01권한이 지배한다

필요 측추력이 위협에 따라 125N → 300N으로 상승. 요격 성패를 좌우하는 건 미사일의 divert 권한이다.

02불가능 영역

지연(시커·오토파일럿·자세루프)을 반영하면 9g 드론은 Coyote급으로 대부분 요격 불가('X'). 이상화된 즉응 제어일 때는 사라졌던 한계다.

어떻게 작동하나

물리는 뉴턴 강체 동역학, 유도는 비례항법, 설계 탐색은 네 알고리즘이 같은 목적함수를 놓고 겨룬다.

GUIDANCE비례항법 (PN)

표적이 시야각에서 미끄러지는 속도(LOS rate)에 비례해 가속: a = N·Vc·λ̇. 이를 측추력으로 실현한다. 유도게인 N은 설계변수.

OBJECTIVE공유 목적함수

J = w₁·시간 + w₂·연료 + w₃·최소접근. 회피가 랜덤이라 설계마다 8회 몬테카를로 평균으로 강건 성능을 평가한다.

GRID · GRADIENT격자탐색 · 경사법

격자는 모든 조합을 전수 시도(전역보장·느림). 경사법(L-BFGS-B)은 기울기로 내려가 빠르나 국소최적·과추력에 빠진다.

GENETIC · PPO유전 알고리즘 · 강화학습

유전 알고리즘은 우수해를 교배·변이시켜 진화(표본효율 우수). PPO는 유도법 없이 매 스텝 측추력을 시행착오로 학습한다.

정직한 발견

결과를 미화하지 않았다. 실험 설계의 결함을 찾아 고친 과정과 스케일 의존적 결론을 그대로 남긴다.

01
유전 알고리즘이 우승.

그리드의 1/5 평가(458회)로 최소 목적함수와 최소 연료를 달성. 경사법은 추력을 과하게 배정해 연료를 낭비했고, PPO는 요격을 배우나 종말 정밀도가 부족했다.

02
'전방 장착 최적'은 스케일에 의존한다.

큰 초음속 미사일에선 측추력기 장착 위치가 명중을 좌우했지만, 저속 소형 Coyote급에선 병진 divert 힘이 지배적이라 위치는 연료만 좌우했다. 이 반전을 그대로 보고한다.

03
드론 생존은 peak-g가 아니라 속도가 좌우한다.

느린 드론은 아무리 세게 꺾어도 짧은 종말시간 동안 멀리 못 도망친다. 회피 성패의 지배 변수는 드론 민첩성이 아니라 속도 상한 × 요격탄 권한이었다.

04
가정은 모두 실제 제원에 앵커링.

난이도를 억지로 만들지 않았다. 질량·속도·탄두는 Coyote Block 2 공개제원, 지연은 유도·자세루프 표준 시정수, 회피 g는 현실 드론 범위. 23개 자동 테스트로 물리를 기계 증명했다.

2D 측추력기 요격 시뮬레이터. 파이썬 물리 엔진(RK4·비례항법·몬테카를로)으로 궤적을 계산해 JSON으로 내보내고, 브라우저 캔버스로 재생한다. 개인 연구 포트폴리오.
