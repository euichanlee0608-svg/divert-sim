키보드로도 조종
조종

준비되셨나요?

조이스틱을 좌우로 밀어 미사일을 드론 쪽으로 유도하세요. 살상 반경 안에 들면 명중입니다.

전투용이 아니라 물리·제어를 눈으로 익히는 교육용 시뮬레이션입니다. 회피 드론은 무작위로 방향을 틉니다.

순위표

가장 빠르게 요격한 순서입니다. 시간이 같으면 측추력을 적게 쓴 기록이 위로 갑니다.

    해보니 어땠나요?

    생각보다 어렵습니다. 미사일은 빠르고, 드론은 작고 갑자기 방향을 틉니다. 사람이 손으로 맞추기 어렵기 때문에, 실제 요격 미사일은 비례항법이라는 자동 유도 규칙으로 스스로 표적을 쫓습니다.

    이 프로젝트는 그 자동 유도를 2D 물리 엔진으로 구현하고, 미사일의 설계값(옆으로 미는 힘의 크기·방향, 유도 민감도)을 어떻게 정해야 가장 잘 맞추는지를 실험한 개인 연구입니다.

    여기까지가 전부입니다. 더 궁금하면 아래로 내려가 자동 유도의 궤적과 실험 결과를 볼 수 있습니다.

    아래는 기술 상세 · for the curious

    자동 유도가 조종하면

    사람 대신 비례항법이 미사일을 조종한 궤적입니다. 최적 설계일 때와, 미는 힘이 부족할 때를 비교해 보세요.

    미사일 드론 측추력·기폭

    최적화 방법 비교

    같은 목적함수(요격시간·연료·정확도의 가중합)를 네 가지 방법으로 최소화했습니다. 운용점은 7g로 회피하는 드론, 탐지거리 250m, 응답 지연 반영. 낮을수록 좋습니다.

    요격에 필요한 최소한의 힘

    드론이 세게 회피하고 멀리서 탐지할수록 더 큰 힘이 필요합니다. 'X'는 이 소형 미사일의 힘(≤300N)으로는 90% 명중이 어려운 조건으로, 현실적인 응답 지연을 넣자 나타났습니다.

    필요 최소 측추력 [N] · 명중률 90% 기준
    ← 탐지거리 [m] →

    힘이 결정한다

    필요한 힘이 조건에 따라 125N에서 300N으로 늘어납니다. 명중을 좌우하는 것은 미사일이 옆으로 낼 수 있는 힘의 크기였습니다.

    닿지 않는 영역

    응답 지연을 반영하면 9g로 회피하는 드론은 이 급의 미사일로 대부분 맞추기 어렵습니다. 지연이 없던 이상적 조건에서는 보이지 않던 한계입니다.

    작동 방식

    뉴턴 강체 동역학으로 움직이고, 비례항법으로 유도하며, 네 방법이 같은 목적함수를 놓고 설계를 탐색합니다.

    유도비례항법

    표적이 시야에서 미끄러지는 속도에 비례해 가속합니다 a = N·Vc·λ̇. 이를 옆으로 미는 힘으로 냅니다. 민감도 N은 설계값입니다.

    목적함수무엇을 최소화하나

    J = 시간 + 연료 + 빗나간 거리의 가중합. 회피가 무작위라 설계마다 8회 평균으로 평가합니다.

    전역 · 경사격자탐색 · 경사법

    격자는 모든 조합을 시도합니다(느리지만 확실). 경사법은 기울기를 따라 내려가 빠르지만 국소해에 갇히기도 합니다.

    진화 · 학습유전 알고리즘 · 강화학습

    유전 알고리즘은 나은 설계를 교배·변이시킵니다. 강화학습(PPO)은 유도 규칙 없이 조종을 시행착오로 배웁니다.

    실험하며 알게 된 것

    01
    유전 알고리즘이 가장 효율적이었다.

    격자탐색의 5분의 1 평가로 가장 낮은 목적함수와 연료에 도달했습니다. 경사법은 힘을 과하게 배정해 연료를 더 썼고, 강화학습은 요격은 배웠으나 마지막 정밀도가 부족했습니다.

    02
    설계 결론은 미사일 크기에 따라 달라졌다.

    큰 초음속 미사일에서는 옆으로 미는 장치의 위치가 명중을 좌우했지만, 느리고 작은 이 급에서는 미는 힘 자체가 지배적이라 위치는 연료에만 영향을 주었습니다.

    03
    드론의 생존은 민첩함보다 속도가 좌우했다.

    느린 드론은 아무리 세게 꺾어도 짧은 시간 동안 멀리 못 벗어납니다. 결정적 변수는 회피 능력이 아니라 드론의 속도 한계와 미사일의 힘이었습니다.

    04
    수치는 실제 제원에서 가져왔다.

    질량·속도·탄두는 공개된 소형 대드론 요격탄 제원을, 응답 지연은 표준 유도·자세 시정수를, 회피 성능은 실제 드론 범위를 참고했습니다. 물리는 자동 테스트 23개로 검증했습니다.

    단거리 지대공 요격 미사일의 유도와 최적 설계를 다룬 2D 물리 시뮬레이션입니다. 비례항법 유도를 물리 엔진으로 구현하고, 네 가지 최적화 방법을 동일한 조건에서 비교했습니다. 질량·속도·탄두 등 수치는 공개된 소형 대드론 요격탄 제원과 표준 문헌을 근거로 하며, 물리는 자동 테스트로 검증했습니다. 상단의 조종 데모는 브라우저에서 실시간으로 계산됩니다.
